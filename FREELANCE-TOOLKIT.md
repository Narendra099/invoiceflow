# Freelance Toolkit — Getting Your First Paid Client

You now have a real, deployed, full-stack app (InvoiceFlow) to point to. This file turns that into income. Work through it top to bottom.

---

## Step 0 — Before you apply to anything

1. **Deploy InvoiceFlow** so you have a live URL (Vercel for the frontend, Render for the backend — both free). A live link converts 5× better than a GitHub repo alone.
2. **Push it to GitHub** with the README. Pin it on your profile.
3. **Record a 60-second screen demo** (Loom, free): add a client → create an invoice → mark paid → export PDF. Put the link in every proposal.

A clickable demo + clean repo + Loom video is a portfolio that beats 90% of new freelancers.

## Step 2 — Fiverr "gigs" (productized services)

Fiverr rewards specific, packaged offers. Create 2–3 gigs:

1. **"I will build a full-stack web app with React and Node.js"**
   - Basic $X: one page + simple API. Standard: multi-page + DB. Premium: auth + dashboard + deploy.
2. **"I will build or fix a REST API in Node.js or Java Spring Boot"**
3. **"I will fix bugs in your React, Node, or TypeScript project"** (great for fast first reviews)

Tip: price the Basic tier low at first (to win your first 3–5 reviews), then raise.

## Step 3 — The proposal template (Upwork)

Keep it short. Clients skim. Lead with their problem, not your life story.

```
Hi [Name],

You're looking for [restate their need in one line] — I can do this.

I recently built a full-stack [React + Node + TypeScript] app (InvoiceFlow):
client management, invoice builder, payment tracking, PDF export.
Live demo: [link]  •  Code: [github]  •  2-min walkthrough: [loom]

For your project I'd:
1. [specific first step tailored to their post]
2. [second step]
3. [deliver + how they'll review it]

I can start [today/this week] and keep you updated daily.
A couple of quick questions: [1 sharp question that shows you read the post].

Best,
[Your name]
```

**Rules that win jobs:**
- Mention something specific from *their* post in the first two lines (proves you read it).
- Always include the live demo link.
- Ask one smart question — it starts a conversation and signals you think.
- Apply to **fresh** posts (< a few hours old) with **few proposals**. Same "be early" principle as bounties.
- Target small fixed-price jobs ($30–$150) first to build reviews fast, then scale rate.

## Step 4 — Local / direct outreach (highest rates, least competition)

Small businesses near you often need a simple website or internal tool and will pay more than marketplace clients.

**Who to contact:** local restaurants, gyms, salons, tradespeople, real-estate agents, small shops — anyone with a bad or missing website.

**Cold email/DM template:**
```
Subject: Quick idea for [Business Name]'s website

Hi [Name],

I'm a web developer based in [city]. I came across [Business] and noticed
[specific: no website / not mobile-friendly / no online booking].

I build fast, modern sites and small web tools. I recently built [InvoiceFlow demo link]
to show the kind of clean, functional work I do.

I'd be happy to put together a simple [one-page site / booking form / quote tool]
for [Business] — would a quick 10-minute call this week work?

Best,
[Your name] — [portfolio link]
```

Send 5–10 personalized messages a day. Personalization (the "specific" line) is what gets replies.

## Step 5 — Pricing starting points

| Service                              | Starter price (raise as you get reviews) |
| ------------------------------------ | ---------------------------------------- |
| Bug fix / small feature              | $30–$80                                  |
| Simple one-page site                 | $100–$300                                |
| Full-stack CRUD app (like this one)  | $400–$1,500                              |
| REST API (Node or Spring)            | $200–$800                                |
| Hourly rate (when you switch to it)  | $20–$40/hr to start                      |

Always agree on scope **in writing** before starting. Use milestones for anything over a few hours so you get paid in stages.

---

## Step 6 — The weekly rhythm

- **Daily:** 5–10 tailored proposals/DMs. Volume + personalization wins.
- **Weekly:** add one new feature to InvoiceFlow (auth, multi-currency, email-the-invoice) — turn it into a new gig and a new Loom.
- **After every job:** ask for a review. Reviews compound; the first 5 are the hardest and most valuable.

---

## Reality check

Your first client usually comes after **20–50 quality applications**, not 2–3. That's normal — most people quit at 5. The portfolio piece you now have puts you ahead of nearly everyone applying with nothing to show. Be consistent, be early, personalize every message.
